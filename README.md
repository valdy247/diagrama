# VMV Business — Brand Website (UI/UX Preview)

A responsive, English-language **single-page marketing website** for the VMV Business ecosystem, preserving the approved black-and-white style and white, edge-to-edge canvas.

## Sections

- Hero: Your business. Better connected. with original monochrome SVG artwork.
- Brand positioning and connected-platform vision.
- Six products: VMV Call, VMV Agents, VMV Sites, Inventory, Calendar, CRM & Leads.
- Planned extensions: orders, marketing, analytics, billing, employees and automations.
- Concept web dashboard with illustrative data only.
- Bilingual English–Spanish calling explanation and fictional conversation preview.
- Modular personalized mobile-app design preview.
- App vs. web vs. app-to-web responsibilities.
- Examples for bakeries/retail, contractors and salons.
- Onboarding approach, brand statement, FAQ and closing presentation.
- Responsive in-page navigation and native HTML FAQ disclosures.

## Prototype limits

This is frontend marketing-site design, not a functioning business-management platform. It cannot log in, place real calls, perform AI actions, manage business records, make bookings or accept payments. It does not connect to the existing VMV Call services. Dashboard data and sample conversations are fictional. Planned features are not represented as commercially available.

## Development

    npm install
    npm run dev

## Build

    npm run build

Vite builds the static site to dist/. Vercel deploys from main. No Three.js, external fonts or images, or backend dependencies are needed. The HTML is in index.html, and full-page responsive styles are in src/site.css.
